The wiring alone reproduces early Alzheimer's staging.

Give the model nothing but the connectome and a starting point in the entorhinal cortex, and the order in which regions are reached correlates with the Braak tau stages pathologists describe in post-mortem tissue: temporal pole, parahippocampal and fusiform cortex first, then cingulate and insula, then the rest.

The result holds in a window. Raise the spread rate far enough and strongly connected distant hubs jump the queue, and the ordering breaks down. The simulator sweeps that parameter and shows you the window, so the claim comes with its own range of validity.

Against chance: shuffling the Braak labels gives a 95th-percentile ρ of 0.20 (2,000 permutations), and rewiring the connectome with the same density and weights gives 0.29 (200 graphs). Moving the seed breaks it: fusiform +0.44, superior parietal -0.23, precentral -0.39. Only the entorhinal start, where Braak staging begins, produces Braak order. reproduce.py regenerates every number on this page.

How it works

dx/dt = −β L x − κ x + s

Each of 68 cortical regions holds a pathology load, x. At every step, load flows from regions that have more of it to connected regions that have less, in proportion to how strongly they are wired together. That flow is the graph Laplacian, L, of the connectome. The brain clears some of it each step, and the seed regions keep producing more.

This is linear network diffusion, the model Raj, Kuceyeski and Weiner proposed in 2012 to explain why atrophy patterns in dementia look like the brain's own network structure.

β, the spread rate
How fast pathology moves along connections. The ordering is most Braak-like at low β.
κ, the clearance rate
How fast the brain removes pathology. Higher κ means less reaches distant regions.
APOE genotype
Scales β and κ. ε4 is modelled as faster spread and weaker clearance; ε2 as the reverse. These multipliers reflect the direction of known effects and are not fitted to biomarker data.
Seed
Where pathology begins. Braak staging starts in the entorhinal cortex, bilaterally, so that is the default.

Data and references

Connectome

Group-average structural connectivity from Human Connectome Project diffusion MRI, 68 regions of the Desikan-Killiany atlas, as distributed with the ENIGMA Toolbox (Larivière et al., Nature Methods 2021). Values are log-transformed streamline counts.

Braak reference

Cortical regions grouped into tau Braak stages following the tau-PET staging scheme of Schöll et al., Neuron 2016. Stage II is hippocampal and is not part of the cortical parcellation.

What this is not

A finding. The core result reproduces a published model on a group-average connectome. There is no individual variability in wiring, no regional vulnerability, no protein-specific kinetics, and no vascular contribution. The simulator exists so that each of those can be added and tested against the same baseline.

Run it yourself

Clone the repository, pip install -r requirements.txt, then streamlit run app.py. Upload your own connectome as a CSV with region labels in the first row and column.
